# Strapi Local Setup – Task 1

## Steps Performed

1. Created a new Strapi application using the official CLI
   npx create-strapi-app@latest my-strapi-app --quickstart

2. Started Strapi locally
   yarn develop

   Application runs on:
   http://localhost:1337

3. Accessed Admin Panel
   http://localhost:1337/admin
   Created admin user account.

4. Created a sample content type
   - Collection Type: Article
   - Fields:
     - title (Text)
     - description (Rich Text)
     - published_date (Date)

5. Added sample content
   - Created and published one Article entry from Content Manager.

6. Initialized Git and created branches
   - main
   - jatin-shahare

7. Pushed code to personal GitHub repository
   - Raised Pull Request from jatin-shahare to main.

8. Recorded Loom video demonstrating:
   - Local Strapi setup
